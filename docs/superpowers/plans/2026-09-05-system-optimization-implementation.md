## 并行工作单元

1. 工具体验：手机搜索首屏可达；URL 保存视图、搜索、分类、子分类和精选；正确处理首次直接打开、刷新、前进后退、清空、未知参数；保持 18/36 展示及 resize 后已加载数量。预计算逐字段搜索文本，保留原匹配语义。
2. 导航与媒体：展开菜单焦点离开时关闭，保持 Escape 焦点恢复；减弱动效时不挂载 MP4 source；默认保留动画并提供暂停/继续；静态 Hero 图继续服务端输出、优先加载，不引入首屏空白或布局位移。
3. 发布质量：沿用既有包管理意图，固定锁文件；统一检查脚本；GitHub CI 运行同一套检查，但不新增自动生产部署链；构建入口包含内容与代码检查，避免只有一个不约束构建的独立绿色 CI。说明平台构建覆盖和分支保护仍需权限核对。
4. 内容合同与文案：阅读时长从正文推导；联系 CTA 准确表述为联系与合作；Blog/Work/Lab 对日期、必填字段、顺序、封面等进行共享原语验证；添加正常与失败路径测试，保护当前内容和现有解析语义。
