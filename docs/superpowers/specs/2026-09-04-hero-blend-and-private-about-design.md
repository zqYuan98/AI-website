# Hero 球体融合与匿名化简介设计

日期：2026-09-04

## 背景

当前首页已经使用用户提供的 GIF 球体，但 GIF 自带不透明的浅蓝方形背景。它在左右分栏的 Hero 中形成清晰的矩形边界，压住页面原有的光晕与点阵，整体看起来像一张贴上去的图片。球体本身还叠加了整图阴影和旋转漂移，进一步强化了贴片感。

关于页与站点元数据目前包含真实姓名和较旧的个人简介。用户要求在全站可见内容、SEO 与社交分享信息中移除真实姓名，同时保留「维他命」和 GitHub 用户名，并使用新的职业叙事。

## 目标

- 保留用户提供的大幅 GIF 动画，让球体仍是 Hero 的核心视觉。
- 通过高清静态底图、半透明动态层和边缘羽化消除 GIF 的矩形边界。
- 在桌面端与移动端保持清晰、协调的构图，不遮挡文字或造成横向滚动。
- 对减少动态效果的用户展示清晰静态图。
- 将首页、页脚、关于页、SEO 和分享文案统一到新的匿名化简介。
- 从当前源码与生成页面中移除真实姓名；保留品牌名「维他命」和 GitHub 用户名。

## 非目标

- 不重做导航、作品卡片、博客列表或全站视觉系统。
- 不替换用户提供的 GIF，也不重新生成球体素材。
- 不修改作品与文章正文中的职业经历表达，除非其中出现真实姓名。
- 不清洗既有 Git 历史；匿名化范围是当前分支源码与新生成的站点内容。

## Hero 视觉方案

采用用户选择的 A 方案：「高清静态底图 + 羽化动态层」。

### 图层结构

Hero 右侧保留现有艺术容器，并在同一裁切坐标中叠放两层：

1. 底层使用 `/images/home/hero-orbit.png`，由 `next/image` 优化，负责清晰轮廓、玻璃质感和稳定色彩。
2. 上层使用 `/images/home/hero-orbit-loop.gif`，保持未优化以保留动画，以约 0.62–0.68 的透明度提供球体与轨道运动。

两层共享 `object-fit: cover`、`object-position: center 43%` 和相同缩放，避免可见错位。艺术容器约为 620×340px，允许上下略微超出 Hero 后由 section 裁切，使球体视觉尺寸比当前略大。

### 融合处理

- 在图层容器上使用椭圆径向 `mask-image`：中心约 56% 保持实心，73% 后逐步过渡到透明，边缘在 100% 完全消失。
- GIF 轻微降低饱和度与对比度，并略微提亮，使其背景更接近页面的浅蓝白渐变。
- 删除图片本身的 `drop-shadow`；在球体下方使用单独的模糊椭圆投影，阴影不再暴露整张方图边界。
- 移除旋转，只保留 8 秒左右、约 3px 的轻微上下漂浮。GIF 自身承担主要动态。
- 页面现有光晕和点阵继续位于图片周围，形成统一环境光，而不是被不透明方图截断。

### 响应式与减少动态

- 900px 以下切换为文字在上、球体在下的单列结构，并使用独立的宽度与裁切参数。
- 390px 宽度下球体仍应完整可辨，左右不出现方形边缘，页面 `scrollWidth` 不超过视口宽度。
- `prefers-reduced-motion: reduce` 下停止 CSS 漂浮并隐藏动态叠加层，只保留高清静态底图。
- 静态底图为装饰层，使用空 `alt`；动态图保留现有描述性替代文本。

## 简介与隐私文案

### 统一短简介

首页 Hero 与页脚使用同一句短简介：

> 从视觉算法走向 AI 产品，长期关注技术如何进入真实工作。

页脚不再在这句话后追加现有的「欢迎一起讨论产品、研究与写作。」尾句，确保两处文案完全一致。

Hero 的品牌标题「你好，我是维他命。」与主张「从让模型看见，到让 AI 真正工作。」保持不变。

### 关于页

关于页标题保留「你好，我是维他命」，标题下的引导语改为：

> 从视觉算法走向 AI 产品，长期关注技术如何进入真实工作。

正文替换为以下三段，不额外添加姓名、公司名或职位名：

> 职业起点是算法工程师，做过人脸识别、活体检测和工业视觉缺陷检测。后来，工作逐渐延伸到算法平台、应用平台、钢印 OCR 研发，以及软件、硬件和项目交付。

> 这些经历让我越来越确定：AI 产品最难的部分往往不在模型本身。问题是否真实、数据能否稳定获取、错误如何被发现和接管、结果由谁确认、产品怎样验收，以及一次交付能否沉淀为下一次可复用的能力，才真正决定它能不能落地。

> 因此，我把长期方向定义为「AI 时代的产品经理」：保留对技术和能力边界的判断，同时连接业务、用户、工程与组织，让 AI 不只停留在演示中，而是真正进入工作、被使用、被验证并持续产生价值。

职业路径、工作原则、联系模块继续保留，因为它们支持上述叙事且不包含真实姓名。

### SEO 与数据结构

- 删除 `site.realName`，避免后续页面重新引用真实姓名。
- 站点默认描述改为：「维他命的个人品牌站：从视觉算法走向 AI 产品，记录技术如何进入真实工作。」
- 关于页描述改为：「关于维他命：从视觉算法走向 AI 产品，长期关注技术如何进入真实工作。」
- Open Graph 与 Twitter 继续复用匿名化后的 `site.description`。
- 保留 `site.displayName`、`site.githubUser` 和 `site.githubAlias`。
- 最终对 `src`、`content` 与公开文档运行真实姓名全文搜索；当前站点源码不得存在匹配。

## 预期改动范围

- `src/app/page.tsx`：将 Hero 主视觉改为静态底图与 GIF 动态叠层。
- `src/app/globals.css`：加入羽化、双层定位、地面投影、响应式与减少动态规则。
- `src/lib/site.ts`：更新短简介与默认描述，删除真实姓名字段。
- `src/app/about/page.tsx`：替换元数据、引导语和三段简介正文。
- `src/components/footer.tsx`：移除 `site.tagline` 后的旧邀请尾句。
- 必要时更新既有设计说明，使其不再声明旧的单层 Hero 行为。

## 验收标准

- 桌面端 1392×928：GIF 矩形边界不可见，球体与页面背景自然过渡，文字清晰，作品和博客区域布局不回退。
- 移动端 390×844：球体足够大、无横向滚动、图片无 404。
- 在测试环境临时暂停外层 CSS 漂浮后，两次间隔约 900ms 的 Hero 图像截图仍存在明显像素差异，证明差异来自 GIF 帧而非容器位移。
- 模拟减少动态效果时只显示静态球体，CSS 动画名称为 `none`。
- 首页、关于页和页脚显示新版匿名化简介；页面与 SEO 中不出现真实姓名。
- ESLint 与 Next.js 生产构建通过。
- 推送到 `origin/main` 后，Vercel Production 状态为 `Ready`；首页与两张 Hero 素材均返回 200，线上浏览器无错误日志。
