# 首页轨道小助手 · 设计定稿

状态：用户已确认互动草图、形象、大小与本接入方案，进入实施。只涉及首页动效控制，不包含自动上线。

## 目标与视觉边界

移除首页“暂停动效 / 播放动效”文字胶囊按钮，用蓝白小机器人承接同一项控制。保留现有大球、品牌头像、首屏文字、排版、作品区和其余页面。

已确认的本地参考：`.superpowers/brainstorm/orbit-robot-20260905/orbit-companion.html`。这是独立草图，不应把它的示例导航、预览条、说明区或简化作品卡搬进正式站点。

- 机器人沿用草图的白色圆润机身、深蓝面罩、蓝色眼睛与 NV 标记，位于大球右上侧。
- 桌面按钮区域约 122×142px，窄屏约 98×117px；中间尺寸连续适配。保持草图中机器人相对球体的比例。
- 外层点击区域固定；只有内部头部与眼睛响应指针，不让按钮追着鼠标移动。
- 在现有 Hero 内定位，不遮挡标题或 CTA、不被图片渐隐遮罩裁切，不增加全站悬浮入口。
- 首次进入本次首页组件时显示轻量提示“轻点小助手，让星球休息”，首次点击后隐藏；悬停与键盘聚焦仍可看到下一步操作提示。无需持久化提示状态。
- 不引入聊天、语音、主动弹窗、消息、人物身份替换或额外营销文案。

## 交互合同

### 1. 清醒与休眠

正常动效偏好下首次进入首页保持原有大球自动播放。鼠标在球体区域移动，机器人眼睛轻微追视（约 ±4px / ±2.5px），头部轻微倾斜（约 ±5°）；移出区域回到中性姿态。只对精细指针启用，不把触摸滑动当作追视。

媒体可正常操作时，点击机器人切换持久到本次挂载结束的用户意图（自动播放受阻的重试例外见降级规则）：

| 用户意图 | 机器人 | 视频与装饰动效 | 下一步操作 |
| --- | --- | --- | --- |
| 清醒 | 睁眼，允许轻微追视 | 仅在可见、前台、无减弱偏好、媒体可用时运行 | 让星球休息 |
| 休眠 | 闭眼，保留草图休眠姿态 | 视频、漂浮、光晕均暂停，追视关闭 | 唤醒星球 |

移开鼠标、失去焦点、滚出再滚入或切换后台再回来，都不得自行改变休眠意图。重新进入或刷新首页可回到默认清醒，不增加 localStorage 或全站状态。

### 2. 环境状态优先于播放意图

将“用户希望清醒 / 休眠”与“媒体当前是否播放”分开。滚出视口或切到后台只暂停实际播放，不把清醒意图改为休眠；恢复可见时只有清醒状态可以继续。

开启系统减少动态效果时：

- 冷启动不设置视频 src/source，不请求 MP4；切换为减少动效时暂停并移除已有视频地址。
- 停止追视、倾头、漂浮等动画，保留静态大球与机器人。
- 点击仍可静态切换睁眼 / 闭眼；提示与辅助名称改为“让小助手休息 / 唤醒小助手（静态模式）”，不暗示会播放视频。
- 偏好恢复正常时遵循此前用户意图，休眠者不自动唤醒。

### 3. 输入与可访问性

- 机器人使用真正的 button，触摸点击、Enter、空格均只切换一次。
- 保留清晰的键盘焦点轮廓；SVG 装饰对辅助技术隐藏。
- `aria-pressed` 明确表示用户是否选择休眠；`aria-controls` 指向视频。动态辅助名称和提示文字说明下一步动作。
- 不以悬停临时暂停替代点击暂停，不要求用户一直把鼠标停在球体上。

## 架构与性能

沿用首页服务端组件及 `HeroMotion` 局部客户端边界：

- 首页继续输出现有静态 Image 并通过 children 传入动效层，保留图片尺寸与加载优先级。
- `HeroMotion` 负责用户意图、系统偏好、可见性、媒体播放结果及按钮回调；机器人仅接收展示状态和回调。
- 将机器人的 SVG 与表现封装成小型展示组件；定位 / 焦点 / 表情样式限于首页，不能影响工具等模块。
- 追视仅在本区域指针事件中通过 requestAnimationFrame 合并更新 CSS 变量，不逐帧更新 React 状态，不使用永久 JavaScript 动画循环。
- 组件卸载时清理事件、观察器、待处理帧与媒体播放；对异步 play 的结果做失效保护，快速点击不会使旧请求覆盖新意图。
- 复用原视频与静态图，机器人采用草图矢量图形，不新增视频、大型动画资源、WebGL、动画库或第三方 SDK。

## 加载与失败降级

- JavaScript 尚未就绪或被禁用时，静态大球可见；机器人可作为静态装饰，但不暴露一个无法操作的按钮。按钮启用不应改变预留尺寸或造成布局跳动。
- 自动播放被浏览器拒绝时不后台重试，展示待播放状态，保持清醒意图与中性睁眼表情，`aria-pressed=false`。这是普通点击切换的例外：提示与辅助名称为“播放星球动画”，首次显式点击保留清醒意图并重试，而不是切到休眠；成功后才恢复“让星球休息”的切换规则。再次被拒绝则保持待播放，等待下次显式点击。迟到的拒绝结果不能覆盖用户后来选择的休眠意图。
- 视频加载错误时隐藏视频覆盖层并停止关联动画，显示静态首图与中性机器人；机器人此时作为非交互装饰，不保留无效按钮或进入 Tab 顺序，同时提供“动图暂不可用”的可访问说明。保持机器人位置，暂不提供自动重试循环或另建错误弹窗。
- 正常播放与首图回退都不应遮挡导航、正文或按钮点击。

## 验收

1. 320 / 390 / 768 / 1024 / 1440px 对照原首页：无横向溢出；机器人、提示、焦点不被遮罩裁切，标题及 CTA 保持原布局。
2. 鼠标追视可感知但幅度克制；外层点击目标固定，移出回正。
3. 点击休眠：视频时间不再增长，装饰动效暂停、闭眼；移入移出及后台恢复不唤醒。再次点击正常继续。
4. 手机轻点及 Enter / 空格与鼠标语义相同；辅助名称、pressed 状态和提示同步。
5. 独立减少动态效果冷启动：无 MP4 请求、无追视；静态表情切换及偏好恢复保留用户意图。
6. 无 JS、媒体错误、自动播放拒绝均有静态首图，不出现黑块、死按钮或无止境重试。快速切换不会让视频意外恢复。
7. 内容 / 工具 / lint / 类型 / 生产构建检查继续通过，首页仍静态预渲染；含首页在内的 13 个公开路由及维护入口隔离不回归。
