验收日期：2026-09-08。测试数据均为虚构书签或已有公开资源，未向模型服务发送真实私人收藏。

## 已验证的行为

- 新导入在独立批次中暂存，同批重复保留全部来源，并对照现有、归档及公开快照资源。UTM 清理保留其他查询字段的编码和顺序；同站不同路径不会直接合并。
- 隔离 PostgreSQL 测试覆盖并发同网址导入、幂等收据、版本冲突、归档恢复、明确字段合并、事务回滚以及撤回保护。曾发布、原有、后来编辑的资源不会被普通整批撤回误删。
- API 配置仅所有者可用；密钥以独立主密钥加密，不在响应、备份或浏览器存储中回显。保存配置不发起模型调用，固定虚构测试通过后才能启用。
- API 地址及候选域名校验包括公网 DNS、混合私网结果、固定请求 IP、禁止重定向、超时及响应大小限制。待发送内容只包含确认范围的标题与域名；备注、文件夹、完整链接及敏感路径不发送。
- 持久分析任务覆盖暂停、取消、手动修改优先、配置版本改变、请求预算、共享并发、派发失败和可能已计费的未知结果。未知调用不会自动重试或换服务商。
- 真实路由回归覆盖三个接口的所有者、Origin、请求流大小及禁止缓存边界；Workflow 只接收服务端任务 ID。

## 容量与实际限制

书签每批 2 MiB / 5000 条；管理库 20000 条且 PostgreSQL JSONB 不超过 32 MiB。模型每次最多确认 500 个候选，分组 1–50 条，配置并发 1–3。预算基于填写的价格估算，不是服务商账单上限。

本机隔离测量约：5000 条暂存 0.6 秒，100 条入库 0.34 秒，接近 20000 条上限预览加提交 2.8 秒，5000 组对照 20000 条完整预览 2.0 秒。32 MiB 边界使用真实 JSONB 字节数检查，超出容量的候选保留失败原因。测试进程约 1.1 GiB RSS 包含内嵌 PostgreSQL 与压力夹具，不能作为生产峰值估计。
