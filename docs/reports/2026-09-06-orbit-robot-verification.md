# 首页轨道小助手 · 本地验收

日期：2026-09-06。依据用户批准的轨道小助手设计；只改首页动效交互，未部署。

## 实现边界

- HeroMotion 保留原服务端图片 children，主页文本、图片优先级、布局与其他模块未修改。
- OrbitRobot 使用已批准草图的 SVG、局部 CSS 和固定点击范围；首次提示在第一次点击后隐藏。
- orbit-motion 将清醒/休眠意图与实际播放分开，管理视口、后台、减少动效、错误与过期 play Promise。
- 指针事件只在球体范围内通过单次 rAF 合并更新 CSS 变量，不逐帧触发 React 渲染。
- 手机渐隐从整个交互区移至纯视觉层，保证机器人、提示与焦点轮廓不被遮罩裁切。
- 没有新增依赖、大图、视频、存储、聊天、第三方服务或全站浮层。

## Chromium 实测

- 320 / 390 / 768 / 1024 / 1440px 截图检查：无横向溢出；按钮、焦点及提示在 Hero 内；原文本和 CTA 未移动。
- 指针轻微追视，点击后闭眼；暂停 700ms 内视频 currentTime 增量为 0，CSS 漂浮为 paused。
- Enter / Space 原生切换；休眠后滚出再滚回仍为 pressed=true、video.paused=true。
- 独立 reduced-motion 冷启动：视频 src=null、MP4 请求数为 0；静态闭眼后恢复普通偏好仍休眠、不加载视频。
- 人为阻断初次自动播放：标签为“播放星球动画”、pressed=false；首次点击恢复播放且仍保持清醒意图。
- 阻断 MP4 请求：视频隐藏、静态首图加载，机器人退出交互及 Tab 顺序，提供“动图暂不可用”说明。
- 禁用脚本：静态首图正常、src=null、无无效机器人按钮。
- 手机尺寸模拟：点击可休眠，无横向溢出。CLI 的设备模拟仍报告 pointer:coarse=false，因此不计为真实触屏验证；实际触屏操作需真机补验。
- 无页面运行时错误；机器人区 axe 检查 0 条确定违规。伪元素背景使工具无法自动判定两处文字对比度，因此该项不能据此宣称全量无障碍达标。

后台可见性与卸载竞态另由控制器自动测试覆盖。此次为本地 Chromium/设备模拟检查，不等同于所有真实手机及浏览器的兼容性认证。
