## 已实现

1. **工具任务路径**：小于 768px 时压缩工具页 Hero，减少重复介绍并隐藏装饰大图，保留桌面视觉。原分类、图标与工具卡片风格不变。
2. **工具状态**：网址保存搜索、分类、子分类、精选、阅读视图及类型；刷新与前进后退可恢复。兼容 Next 同路径导航回到无筛选工具页。搜索逐字段预处理，维持旧匹配规则；默认手机 18、桌面 36 个，主动加载数量跨断点保留。无新增搜索服务或依赖。
3. **动效与导航**：默认大动图保留，提供暂停/播放，滚出视口或页面不可见时暂停。减少动态效果偏好从首次加载起不设置 MP4 地址。无 JavaScript 时显示服务端静态图。菜单焦点离开时关闭，Escape 恢复按钮焦点。
4. **内容合同**：Blog、Work、Lab 共享必填项、真实日期、排序、slug、封面存在性校验；日期统一带引号，防止 YAML 先归一化无效日期。博客时长从正文估算；联系 CTA 改为“联系与合作”，不虚构邮件入口。详情读取改为按 slug 直接查文件。
5. **发布检查**：新增 Bun 锁文件、统一本地/构建检查入口与 GitHub Quality 工作流。内容、工具安全、筛选状态、lint 或类型错误会阻止仓库构建脚本继续。新增生产模式只读 HTTP 冒烟。

保留 268 个工具、258 个本地图标、4 个精选和 6 条阅读资源；公开工具数据不再发送未使用的 `order`、`updatedAt`。没有改写文章正文、案例成果或作者身份，也未新增数据库、监控 SDK、账户或 SEO 基建。

## 使用与边界

- 运行检查：`node scripts/check-quality.mjs`；包含构建：`node scripts/check-quality.mjs --build`。
- 运行冒烟：启动生产服务器后执行 `node scripts/check-smoke.mjs <本地生产服务器地址>`。
- 内容维护见 `docs/content-maintenance.md`；平台发布设置和 CI 的边界见 `DEPLOY.md`。
- 实施完成当时 GitHub 工作流尚未推送；后续远端运行结果见下方“后续正式发布”。Vercel Build Command 覆盖和分支保护仍需要具备项目权限后核实。
- 构建存在一个非阻断提示：Next 忽略 Git 仓库之外的用户目录锁文件。没有修改或删除那个无关文件，也没有扩大打包根目录。
- 浏览器验证为 Chromium 指定视口，不等同真实 iPhone/Safari 或所有设备覆盖。
- 中文验证包含自动化中文输入和网址恢复，不等同所有操作系统输入法的人工验证。
- 真实案例证据、联系邮箱以及第二批架构/内容工作仍待后续；本轮没有替作者编造或扩张功能范围。
