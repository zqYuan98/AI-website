# AI 导入体验修复验收

修复范围见 `docs/superpowers/specs/2026-09-08-ai-import-usability-repair.md`。

## 实现与自动化检查

- 设置未修改时不重复保存；服务端相同配置保存保持启用、测试版本、密钥及任务状态。旧版本写入仍冲突。
- 五条试用在资格、隐私和域名检查后截取，确认绑定准确 ID。剩余资源尚未发送，排除后只减少范围。
- 开始及恢复任务在事务内检查活动任务与有效租约的在途重叠范围；租约过期不会自动重试，也不会永久封锁已取消任务的候选。
- 模型失败仅保留受控错误消息及允许的诊断字段，未知结果保守暂停。
- 保留中的 AI 建议按本批筛选，显示、分类和搜索共享人工优先的拟用字段；不扩大固定收藏选择。
- `node scripts/check-quality.mjs --build` 全部通过，包括真实 PGlite 事务、认证、访问控制、模型传输与隐私、任务恢复、配置状态、筛选、ESLint、类型检查及生产构建。最终在途守卫调整另通过 `check-smart-analysis.mjs`。
- `node scripts/smart-ai-ui-fixture.mjs --check` 通过。新增 fixture 是独立的离线服务；生产入口没有加入测试开关。

## 浏览器操作验证

使用 Codex 浏览器、独立内存 PGlite 和虚构账号。所有模型响应均通过 fixture 注入生成，未调用真实模型或处理生产资源。

1. 新连接已就绪时旧暂停任务单独归入历史。通过主按钮打开最多五个资源的发送预览；排除一项后显示四项，没有补入第五项。
2. 确认这四个虚构资源后看到等待状态，随后自动更新为完成并保留四条建议。
3. 原来已选三个资源保持三个；新增三个分类明确资源显示单独的显式选择入口。AI 建议视图显示本批六条保留结果（含旧建议），没有误称本次生成六条。
4. 设置页连接可用时主要操作是开始整理；没有无修改保存按钮。通过批次内链接进入设置后可返回原批次。
5. 模拟连接测试拒绝后显示安全错误并同步停用状态；模拟测试成功后先显示等待启用，手动启用后恢复就绪。
6. 当前暂停任务的计数、错误、继续和重试入口直接可见。AI 建议列表保留手工简介及手工分类，显示人工内容已保留。
7. 390×844 手机视口：三项导航可见，14px 字体、44px 点击区域，无横向溢出，试用按钮在首屏可见，结果标题获得键盘焦点。已恢复浏览器默认视口。
8. 默认桌面 1280px 宽：去除重复侧栏后，试用按钮完整位于固定收藏栏上方。

## 使用边界

连接测试成功只证明固定样例可用；不同服务的大批量分类仍可能因响应格式、超时或额度失败。现在可以先核对少量结果，并在任务处查看可操作的错误信息。每次真实资源发送及最终收藏仍由所有者确认。
