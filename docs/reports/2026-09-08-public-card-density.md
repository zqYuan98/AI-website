# 公开资源卡片密度优化

## 设计

原网格卡片至少 172px 高，静态分类也占用 44px 的底部操作区，再由 `space-between` 将空白拉开。新版将名称、类型与分类归到卡片顶部，用途说明与真实的推荐操作放在下一行，取消固定最小高度和空操作区。同一网格行仍对齐；长内容可以自然增高。

桌面保留三列，中等屏幕两列、手机一列。标题仍为 17px（精选 18px），用途仍为 14–15px；辅助分类从 12px 增至 13px。外链和推荐按钮点击区至少 44px。列表取消原有固定 145px 操作栏；1100px 及以下精选说明区移至下方，避免挤窄卡片。

不截断标题或说明，不更改公开资源数据、分类与排序。推荐详情维持独立按钮和原有弹窗。

## 验证

- 1440px 视口、AI 与自动化分类：原卡片统一 172px；新版普通行约 107px，含精选推荐的首行约 134px。
- 手机版精选卡片约 131px；901px 精选卡片约 139px；桌面列表首批行约 77px。
- 实际渲染全部 274 个公开资源，1440、1101、1024、901、767、390、320px 下无横向页面溢出，无标题或说明裁切。
- 精选检查 900/901、1100/1101px 断点；网格、列表及手机展示正常。
- 所有卡片外链和推荐按钮均至少 44×44px；推荐详情可打开，关闭后焦点回到原按钮。
- 既有领域、导入、鉴权、模型、路由与公开资源状态检查通过。全量 ESLint、TypeScript、Next.js 生产构建通过。

首次全量 lint 扫描到另一个 `.worktrees` 工作目录的生成代码；已让 ESLint 和 TypeScript 排除该独立工作目录后重新完成检查与构建，未改动其中的文件。此次为展示优化，复用现有验证，没有新增实现镜像测试。
