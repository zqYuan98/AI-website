- `node scripts/check-quality.mjs --build`：通过，包括现有内容、本机资源库回归、搜索、交互、ESLint、TypeScript 和 Next.js 正式构建。
- `scripts/cloud-auth-check.mjs`：真实 Better Auth handler + PGlite PostgreSQL 引擎；正确/错误密码、固定 owner、拒绝其他账号、关闭注册、CSRF、Cookie、过期/退出/重置撤销会话及跨实例限流通过。
- `scripts/cloud-library-check.mjs`：PGlite 中执行实际 SQL/事务；274 条既有公开资源、陈旧版本与并发冲突、普通保存不发布、白名单、回滚、导入撤回、私有恢复、零条公开快照以及私有/认证表权限隔离通过。
- 最终迁移审查后补充并通过回归：公开初始化来源必须显式指定；私人备份、混合 private/inbox 条目、额外顶层字段或未知资源字段均拒绝，不会通过剥离私人标记变成公开内容；合法空快照仍可初始化。
- `scripts/check-cloud-api.mjs`：实际路由配隔离依赖，验证访问门、同源、请求大小、错误不泄漏凭据、发布后缓存失败及幂等刷新，以及云端为空/报错不回退文件。
- `node scripts/check-smoke.mjs http://127.0.0.1:4301`：本机正式构建 13 个公开页面及登录页返回 200；未配置生产管理页、本机 API 和云库匿名读取保持关闭。
- 前轮本机浏览器检查：桌面管理页与 390px 手机入口/管理页/添加表单无横向溢出，搜索和下拉字号 16px，无页面错误提示；确认未启用的正式构建显示「私人资源库尚未启用」。该轮没有创建测试收藏或改动真实私有库内容。
- 首次账号初始化补充回归：使用 Better Auth 同版本公开输入契约校验邮箱；无效邮箱不写入用户、密码账号或会话，首尾空白和大小写规范化后的邮箱可通过实际登录。认证回归和对应 ESLint 通过。
- Neon 权限兼容性修正：角色创建与更新拆开，拒绝接管高权限、跨数据库或异常成员角色；提交前按目标角色检查最小授权，提交后通过独立公开连接验证。PGlite 中用非超级用户 CREATEROLE 身份执行首次创建和重复配置均通过，并确认旧的 `SET ROLE`、`ALTER ... NOSUPERUSER` 会报权限不足。CLI 另校验直连与运行地址属于同分支、数据库和私有角色。
- 已在独立 Neon Free 项目 `vitamin-resource-library-verify` 完成真实 pg 认证与资源库检查：账号、会话、恢复、持久限流、事务、保存不发布、发布回滚、空快照和实际公开连接权限隔离均通过。认证与资源库使用不同数据库，没有在正式库运行测试。公开 ACL 负向检查使用固定连接关闭默认只读后仍被权限系统拒绝，避免 Pool 在错误后重建连接干扰断言。
