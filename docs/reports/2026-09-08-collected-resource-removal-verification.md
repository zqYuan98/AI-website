# 已收藏资源逐条移出：修复与本地验收

## 问题与行为

导入完成的记录原来被统一设为只读：没有直接移出关联收藏的入口，即使从收藏库归档，导入页仍按历史结果显示“已收藏”。

- 导入结果增加显眼的“已收藏”“已移出”视图；列表和详情均可单条移出、恢复。
- 收藏库每行增加相同操作，“已归档”入口改为“已移出”。
- 移出复用现有归档语义，保留内容与来源；恢复为已整理、仅自己可见。
- 关联记录按资源 ID 投影当前名称、网址、用途、分类与状态；统计、搜索和筛选使用相同投影。
- 历史处理结果保持只读，移出后不会重新成为待收藏候选。多条导入记录关联一条收藏时，操作影响同一收藏，确认中说明此影响。
- 已不存在的收藏保留来源说明，不能通过相同网址寻找替代资源或重新创建。
- 公开快照保持独立，已公开资源在操作前提示需另行发布更新。

## 一致性与权限

导入页打开确认时读取当前关联收藏，冻结具体操作、目标、批次版本和收藏库版本。版本冲突要求重新核对，不自动覆盖。重试保留请求 ID，已完成回执不会再次执行；回执重放显示中性结果提示。后端在所有者事务中校验关联、状态及版本，资源变化与回执原子提交。

主收藏库单条操作冻结目标及版本，只提交该条 ID；保留其他勾选。恢复和移出都不触发公开发布。
